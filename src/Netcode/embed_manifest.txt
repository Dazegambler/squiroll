# Embed Manifest
# Format: source_path=target_path[=varname]
#   source_path: path relative to src/Netcode/ (used in #embed directive)
#   target_path: path in the game's virtual filesystem (used in embeds map)
#   varname:     (optional) C++ variable name suffix. Auto-derived from filename if omitted.
#                Required when filenames would collide (e.g. menu.nut in multiple dirs).
#
# To add a new embedded script:
#   1. Place the .nut file under src/Netcode/embed/
#   2. Add an entry here
#   3. Run build.bat (which calls generate_embeds.bat)
#   4. No other C++ changes needed!
